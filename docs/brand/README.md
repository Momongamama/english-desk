English Desk 是一個人的英文口說寫作練習桌。外觀是「孔版印刷小誌＋粉彩」：奶油色紙、黑色粗線、四個粉彩色，加一點錯版和硬陰影。目的是讓每天練習感覺輕鬆、有點好玩，但修正內容永遠清楚好讀。

## 內容原則

- 介面文字用繁體中文；練習內容、範例句、題目用英文。
- 對使用者說「你」，語氣像一起練習的朋友，直接、短句、不說教。例：「說錯就說錯，卡住就用簡單的字繞過去。」
- 按鈕用動詞開頭：「開始對話」「請 AI 批改」「全部存成卡片」。忙碌時改成「批改中…」「整理中…」。
- 錯誤訊息說發生什麼和怎麼辦：「API key 無效，請到設定檢查。」不道歉、不用驚嘆號。
- 不用 emoji 當裝飾。只保留功能符號：✎（AI 的修正）、▶（朗讀）。
- 數字寫阿拉伯數字（10 分鐘、150–200 字），CEFR 等級寫代碼（B2、C1）。

## 顏色

- 底色一律 `bg`；裝內容的盒子用 `surface`。文字一律 `ink`，次要文字 `ink-muted`（只放在 `bg`、`surface` 上）。
- 四個粉彩各代表一種練習，整站固定不換：`tone-coral` 口說、`tone-lilac` 寫作、`tone-green` 今天與跟讀、`tone-yellow` 卡片。大面積用對應的 `tint-*`，小面積強調用 `tone-*`。
- 粉彩上的字一律用 `on-tone`（深色），深色模式也是。
- 修正的視覺語言：原句用 `strike` 刪除線，自然說法下面墊 `highlight` 螢光筆底（淺色是綠色，深色換成深綠才看得清楚）。
- `accent-text` 只給小字強調：eyebrow、到期張數、紀錄裡的等級。
- 一個畫面最多一個 `ed-btn--primary`。
- 顏色不能是唯一的訊號：每格週排程都寫「口說／寫作」，每個狀態都有文字。
- 所有文字在淺色與深色主題都至少 4.5:1；`ink-muted` 不要放在 `tint-lilac` 上（4.4:1）。

## 字體

- 標題字 Bricolage Grotesque（`--font-display`），只用在網站名稱 `brand` 和大數字 `number`。
- 其他全部 Noto Sans TC（`--font-body`）。
- 字級只用 tokens 裡的 8 個：brand、number、title、heading、body、body-strong、small、label。不要新增。

## 形狀與間距（避免越長越亂）

- 圓角只有三種：`radius-sm` 10px（週排程格子、提示列）、`radius-md` 18px（所有裝內容的盒子：卡片、修正、輸入框、對話泡泡、閃卡）、`radius-pill`（所有能按的和標籤：按鈕、chip、分頁、等級徽章）。
- 判斷法：能按的是膠囊；裝內容的是 18px；小格子是 10px。不屬於這三類就是設計錯了，先回來改規範。
- 外框只有一種粗細 `border-width` 1.5px，顏色 `line`。唯一例外是今日任務的錯版外框 `border-width-strong`。
- 陰影只有兩種硬陰影，沒有模糊：`shadow-hard`（選中的分頁、今天、accent 按鈕）、`shadow-hard-coral`（primary 按鈕）。卡片不加陰影。
- 間距只用 `space-1` 到 `space-6`（4、8、12、16、24、32）。卡片之間 `space-5`，卡片內距 `space-4`，同類元素之間 `space-2` 或 `space-3`。
- 內容欄最寬 760px，置中；手機兩側 16px。

## 招牌元素

- 網站名稱的珊瑚色錯位陰影（`ed-brand`）。
- 今日任務卡的錯版珊瑚外框（`ed-task`），全站只用這一次。
- 按下按鈕時往右下位移 2px、陰影消失，像蓋印章。

## 圖示

- 目前不用圖示庫。導覽、按鈕全用文字。
- 功能符號只有 ✎ 和 ▶，用文字字元，不用圖片。
- 沒有 logo；品牌就是用 `brand` 字級排出的「English Desk」。
