      AI 設定

      API key 只存在這台裝置的瀏覽器裡，不會上傳到 GitHub 或任何其他地方。不要在別人的電腦上填。

      使用

      到 Google AI Studio 取得 key，免費額度足夠日常練習。語音對話和跟讀的逐句稿只能用 Gemini，選 Claude 時也請填這組。

      到 Claude Console 取得 key。API 按用量計費，和 claude.ai 訂閱分開。

      字典與考試單字

      閱讀新聞時點字就能查。網站內建開源的 ECDICT 中文翻譯、英英解釋和你的筆記，不用匯入也能用。想看完整解釋和例句，就匯入你自己的字典（例如 english-desk-dict.ndjson.gz），之後會優先查它。考試單字也一樣：沒匯入就用內建清單，匯入總表 CSV 後改用你的清單。匯入的檔案只存在這個瀏覽器，不會上傳；Mac 和 iPhone 要各匯入一次。

      底線樣式：實線是托福、虛線是雅思、波浪線是 GRE。閱讀頁上方可以選要標示哪幾種，或全部關掉。

      發音評分（選填）

      跟讀時用 Azure 發音評估，每個字都有分數。沒填就改用 Gemini 聽了給建議。Azure 免費方案（F0）每月有 5 小時語音額度，一句幾秒鐘，練很久也用不完。

      到 Azure 入口網站 建立「Speech」資源，定價層選 Free F0。建好後在「Keys and Endpoint」複製 KEY 1 和 Location/Region。

      備份

      卡片和紀錄存在這個瀏覽器裡。換裝置、換瀏覽器或清除網站資料前，先匯出備份；在新的地方用匯入還原。
